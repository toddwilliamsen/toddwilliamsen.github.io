Samples

CI/CD security gate samples

Workflows that accompany Security Gating CI/CD Pipelines. Copy into your repo, then tighten paths, languages, and severity thresholds.

  • github-security-gates.yml — GitHub Actions: CodeQL, dependency review, Trivy, gated OIDC deploy
  • azure-devops-security-gates.yml — Azure DevOps: Microsoft Security DevOps, SARIF fail-closed, environment checks

Pair Azure deploy with short-lived identity (OIDC / federation), not long-lived client secrets. See GitHub Actions OIDC Deploy to Azure.
