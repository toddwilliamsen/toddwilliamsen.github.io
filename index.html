Focus

Where the work concentrates

Day to day, that means Azure security architecture, Entra ID and hybrid identity, Microsoft Defender for Cloud and Sentinel, and Python / PowerShell automation that makes secure defaults repeatable.

I also spend a lot of time on the connective tissue: Conditional Access and PIM, Azure Policy and CSPM against NIST and CIS baselines, secure lab and workload provisioning, and the operating details that decide whether governance holds after the design review ends.

Background

Built in operations, sharpened in cloud security

I’m currently a Senior Cloud Security Engineer at Cream City Cyber, where I engineer Azure and GCP lab environments, automate isolated VM lifecycle with ARM and custom images, and drive CSPM and governance work through Defender for Cloud, Azure Policy, and RBAC.

Before that, as a Lead Engineer at CDW, I was a Tier 3 escalation point for premier enterprise clients—repairing hybrid Entra ID / Active Directory failures, enforcing Conditional Access and PIM for Zero Trust access, and guiding Azure compute and SQL posture under real incident pressure.

Earlier roles at Insight and Ascension grounded that work in large-scale modern management: cloud-attached endpoint strategy across thousands of hybrid devices, and engineering leadership for a MECM estate supporting 170,000+ endpoints in a multi-hospital healthcare network under HIPAA, CIS, and NIST expectations.

The through-line is the same: secure the control plane, encode guardrails in the platform, and keep identity, configuration, and detection close enough to operations that security survives delivery pressure.
