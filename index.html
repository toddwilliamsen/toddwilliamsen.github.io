Project

Quantum Helix

Multi-cloud hybrid quantum-classical threat detection.

Quantum Helix ingests AWS and Azure security telemetry, maps it into a Common Information Model, compresses features with classical PCA, then scores threats with a hybrid ensemble: Isolation Forest, classical RBF SVM, and a PennyLane quantum kernel SVM. A variational QNN remains an optional research sidecar.

Alerts emit as AWS Security Hub (ASFF) and Microsoft Sentinel (CEF) payloads, with a React SOC dashboard for triage. Classical baselines stay mandatory so quantum contribution can be measured—not assumed— through detection rate, false-positive rate, subtle-APT recall, latency, and cost.

Background

Built in operations, sharpened in cloud security

I’m a Senior Cloud Security Engineer focused on Azure security architecture, hybrid identity, governance, and automation—engineering secure lab and workload environments, CSPM aligned to NIST and CIS, and policy/RBAC guardrails that hold after the design review ends.

The through-line is the same: secure the control plane, encode guardrails in the platform, and keep identity, configuration, and detection close enough to operations that security survives delivery pressure.
