Background

Built in operations, sharpened in cloud security

I’m a Senior Cloud Security Engineer focused on Azure security architecture, hybrid identity, governance, and automation. I build secure lab and workload environments, CSPM aligned to NIST and CIS, and policy/RBAC guardrails that keep their shape long after the design review ends.

That sits on a long operational foundation: Tier 3 escalation for hybrid Entra ID / Active Directory failures, Conditional Access and PIM for Zero Trust access, Azure compute and SQL posture under incident pressure, and cloud-attached endpoint strategy across large hybrid estates.

Earlier, I led engineering for massive modern-management environments—including a MECM estate supporting 170,000+ endpoints in regulated healthcare under HIPAA, CIS, and NIST expectations. The through-line is the same: secure the control plane, encode guardrails in the platform, and keep identity, configuration, and detection close enough to operations that security survives delivery pressure.

In short: make sure the cloud doesn’t fall over—especially because someone forgot identity, governance, or automation.
