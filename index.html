Exploration

Quantum Helix

A novel way into a practical question about quantum value in cloud security.

Lately, I’ve been exploring whether quantum techniques can offer anything practical for cloud threat detection—even without access to real quantum hardware. With some hype around “quantum cybersecurity,” I wanted to see if quantum kernels running on classical simulators behave differently on subtle cloud anomalies.

To test that, I built a small pipeline that pulls in AWS CloudTrail and Azure Activity/NSG logs, normalizes them into a Common Information Model, and runs them through a feature pipeline using StandardScaler and PCA. Classical models like Isolation Forest and RBF SVM handle the straightforward anomalies, while the more complex edge cases get evaluated by a PennyLane QSVM quantum kernel. I combine the scores through an ensemble layer so I can see where the quantum and classical detectors disagree.

On the engineering side, I built a lightweight SOC-style console using Flask with SSE streaming, React with Vite, and SQLite with SQLAlchemy for event storage. The most interesting part has been seeing where the quantum kernel diverges from the classical detectors—especially on high-dimensional anomalies that don’t look suspicious at first glance.

Still early, but it has been a fun way to explore the question: is there any practical quantum value in cloud security today, even without quantum hardware?

Background

Built in operations, sharpened in cloud security

I’m a Senior Cloud Security Engineer focused on Azure security architecture, hybrid identity, governance, and automation—engineering secure lab and workload environments, CSPM aligned to NIST and CIS, and policy/RBAC guardrails that hold after the design review ends.

That work sits on a long operational foundation: Tier 3 escalation for hybrid Entra ID / Active Directory failures, Conditional Access and PIM for Zero Trust access, Azure compute and SQL posture under incident pressure, and cloud-attached endpoint strategy across large hybrid estates.

Earlier, I led engineering for massive modern-management environments—including a MECM estate supporting 170,000+ endpoints in regulated healthcare—under HIPAA, CIS, and NIST expectations. The through-line is the same: secure the control plane, encode guardrails in the platform, and keep identity, configuration, and detection close enough to operations that security survives delivery pressure.
