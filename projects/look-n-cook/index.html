Look n Cook

A cooking assistant for families. Photograph what’s in the fridge or pantry, confirm the ingredients, and get recipe matches—without sending kitchen photos to the cloud.

Side project·iOS · on-device AI

Look n Cook is a consumer mobile app for the “what’s for dinner?” problem— not Azure, not Sentinel, not quantum kernels. Same builder, different kitchen.

The idea

Most recipe apps assume you already know what you’re making. Look n Cook starts from what you actually have. Snap up to five photos (or type ingredients), let on-device AI suggest what’s in frame, edit the list, then match against a bundled library of roughly 13,500 recipes.

No account required. Saved recipes, shopping lists, and settings stay on the device. You can also skip the camera entirely and type ingredients by hand.

Why on-device

An earlier version leaned on cloud Gemini / Firebase for recipe AI. That path is gone from the mobile app—archived on purpose. The product bet now is local-first:

  • Kitchen photos aren’t shipped to a cloud model for core scanning
  • No API keys and no cloud inference bill required to decide dinner
  • Matching works offline after the one-time model download

Optional RevenueCat subscriptions can gate freemium scan limits when that ships. They’re not required for the core loop.

First launch

On first open, ClearSight AI downloads once over Wi‑Fi—about 350 MB. After that, scanning and recipe matching run locally. If the download fails, you can retry; manual ingredient entry still works so dinner isn’t blocked on a bad hotel network.

How it works

  1. Capture — Take photos of the fridge, pantry, or counter (up to five), and/or type ingredients manually.
  2. Detect — Where package labels are clear, OCR can pull ingredients first. Otherwise ClearSight AI (Liquid LFM2.5-VL via ExecuTorch) reads the photo on-device, with Apple Vision in the mix.
  3. Confirm — Review, rename, remove, or add items before matching. The model proposes; you decide. Missed the mustard? Add it. Thought the remote was a pepper? Delete it.
  4. Match — Search the offline SQLite recipe library with the filters you set.
  5. Cook — Open a recipe, run step-by-step cook mode, build a shopping list for what’s missing, save or share.

Filters that actually matter at 5:30 p.m.

  • Kid-friendly — simpler recipes when the audience is picky
  • Max prep time — 15 to 90 minutes, with an option to count thaw time
  • Servings — default 4, adjustable
  • Meal type — main, side, dessert, snack, breakfast
  • Diet & lifestyle — vegetarian, vegan, gluten-free, dairy-free, nut-free, keto, low carb, diabetes-friendly, paleo, low sodium, heart healthy

Matching recipes show diet badges on results and recipe detail. Filter choices persist on the device.

What else is in the app

  • Browse Recipes — Search the full offline library without scanning.
  • Create Recipe — Write and save your own dishes on the device.
  • Saved / My Recipes — Bookmarks and personal recipes.
  • Shopping List — Missing ingredients pulled from what you want to cook.
  • Order Out — When cooking is not happening tonight, jump to Maps or delivery apps.
  • Wild-game recipes — Curated Look n Cook dishes alongside the main library (venison and friends aren’t an afterthought).

Platform honesty

iOS is primary (deployment target 17.0 for the on-device vision stack). An Android package exists, but ClearSight AI is not fully implemented there yet— so v1 focus is iPhone. That’s intentional scope, not a vague “coming soon” shrug.

Stack (short version)

  • React Native + Expo (Router, camera, SQLite, sharing/print)
  • Zustand for state; AsyncStorage for saved recipes, lists, and settings
  • Bundled SQLite recipe database (~13,500 recipes)
  • ClearSight AI + Apple Vision for ingredient detection
  • EAS / TestFlight for distribution

Data & attribution

Recipe library data includes Epicurious content via josephrmartinez/recipe-dataset (CC BY-SA 3.0), plus Look n Cook curated wild-game recipes. Nutrition estimates, when present, use USDA FoodData Central (CC0).
