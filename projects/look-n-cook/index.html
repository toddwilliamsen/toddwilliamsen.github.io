Look n Cook

A cooking assistant for families. Photograph what’s in the fridge or pantry, confirm the ingredients, and get recipe matches—without sending kitchen photos to the cloud.

Other projects·iOS · on-device AI

This one lives outside the security lane on purpose. Look n Cook is a consumer mobile app for the “what’s for dinner?” problem—not Azure, not Sentinel, not quantum kernels. Same builder, different kitchen.

The idea

Most recipe apps assume you already know what you’re making. Look n Cook starts from what you actually have. Snap up to five photos (or type ingredients), let on-device AI suggest what’s in frame, edit the list, then match against a bundled library of roughly 13,500 recipes.

How it works

  1. Capture — Take photos of the fridge, pantry, or counter, and/or type ingredients manually.
  2. Detect — ClearSight AI (Liquid LFM2.5-VL via ExecuTorch) identifies food items on-device; OCR helps with package labels when it can.
  3. Confirm — Review, rename, remove, or add items before matching. The model proposes; you decide.
  4. Match — Search the offline SQLite recipe library with filters for time, servings, kid-friendly, and dietary needs.
  5. Cook — Open a recipe, run step-by-step cook mode, build a shopping list for what’s missing, save or share.

What else is in the app

  • Browse Recipes — Search the full offline library without scanning.
  • Create Recipe — Write and save your own dishes on the device.
  • Saved / My Recipes — Bookmarks and personal recipes.
  • Shopping List — Missing ingredients pulled from what you want to cook.
  • Order Out — When cooking is not happening tonight, jump to Maps or delivery apps.
  • Filters — Prep time, meal type, vegetarian/vegan/gluten-free and other diet options, with badges on results.

Privacy posture

Default production mode is on-device: vision, recipe matching, and local storage. Kitchen photos are not shipped to a cloud model for core functionality—no API keys and no cloud bill required to decide dinner. Optional RevenueCat subscriptions can gate freemium scan limits when that ships; they’re not required for the core loop.

Earlier cloud Gemini / Firebase recipe AI was removed from the mobile app and archived. The product bet is local-first.

Stack (short version)

  • React Native + Expo (iOS primary; Android bundle id exists)
  • Zustand for state; AsyncStorage for saved recipes, lists, and settings
  • expo-sqlite for the bundled recipe database
  • ClearSight AI + Apple Vision for ingredient detection
  • EAS / TestFlight for distribution

Data & attribution

Recipe library data includes Epicurious content via josephrmartinez/recipe-dataset (CC BY-SA 3.0), plus Look n Cook curated wild-game recipes. Nutrition estimates, when present, use USDA FoodData Central (CC0).

Status

Actively developed toward TestFlight / App Store release. It sits under Other projects so it doesn’t get mistaken for cloud security work—because it isn’t.
